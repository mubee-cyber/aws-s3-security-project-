Securing Cloud Storage Using AWS S3

 Project Overview

This project demonstrates how to secure cloud storage using Amazon Simple Storage Service (Amazon S3).

The aim is to understand cloud storage security and implement security controls to protect stored data from unauthorized access.

 OBJECTIVES 

- Create and configure an Amazon S3 bucket.
- Implement security controls.
- Enable default encryption.
- Block public access.
- Test access permissions.

TOOL USED 
- AWS MANAGEMENT CONSOLE
- CHROME FOR PUBLIC TESTING
- AMAZON S3
- GIT HUB
